# --- Deep learning ---------------------------------------------------------
# torch is installed separately on some platforms; see README for the CUDA
# and CPU index URLs. The lower bound is 2.5 (the first NumPy-2-compatible
# release); there is deliberately **no** upper bound, because the wheels
# published to the CPU index lag PyPI and a hard ceiling makes the requirements
# file uninstallable on a machine that already has a newer build. The code uses
# no torch API newer than 2.5 and no deprecated one, so both directions are safe.
#   CPU-only:  pip install torch --index-url https://download.pytorch.org/whl/cpu

# --- Agentic self-healing (Part C) ----------------------------------------
# Pinned at the 1.x line deliberately. The 0.2.x line is incompatible with
# auto_heal/graph.py: LangGraph >= 1.0 requires an explicit thread_id in the
# graph config before it will write to a checkpointer, and every StateGraph
# invocation now needs {"configurable": {"thread_id": ...}}. Passing the 0.2
# API to a 1.x install raises KeyError; passing the 1.x config to 0.2 raises
# an unexpected-keyword error. The call site passes it, so 1.x is required.

langchain-core>=0.3
langchain-openai>=0.2
